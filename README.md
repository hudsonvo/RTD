# RTD Tracker

A real-time transit tracker for the Denver RTD network, built with React + Vite.

## Features

- Live vehicle positions on an interactive map
- Trip delays and upcoming arrivals by stop
- Service alerts
- Route and stop browsing

## Setup

```bash
npm install
npm run dev
```

## Update static GTFS data

```bash
npm run update-gtfs
```

Downloads the latest stops and route/direction data from RTD's public GTFS feed.
